01 / About

I build AI that runs on your machine.

I'm Varun, a second-year AIML student at RV University. Most of what I build keeps the model on the device: a voice assistant with no cloud in the loop, a dictation app that makes zero network requests, and a browser agent that literally cannot see your passwords.

When a project needs hardware, I wire that up too — ESP32 cameras, Pico-driven lights. When I want to understand something properly, I build it from scratch, like a GPT trained on a laptop CPU.

  3. 03

    Browser security · SIH 2026

    Dhristi

    3 independent fail-safe layers

    A Chrome extension that lets a browser agent see the page without ever seeing your PII. Object detection runs on-device via WebGPU; sensitive fields are blacked out of the screenshot and stripped from the DOM before anything leaves the client, an egress assertion re-checks every request, and an action guard refuses writes to sensitive fields. Built with a six-person RVU team for ISRO's problem statement 26171.

    • Chrome MV3
    • WebGPU
    • Transformers.js
    • FastAPI
    • Python

    MoodSync

    ML from scratch

    tiny-gpt

    ~1.07M params · ~1 h on a laptop CPU

Trained on the complete Sherlock Holmes canon, it nails Victorian style and fails on sense — exactly the expected result at this scale, documented honestly.
